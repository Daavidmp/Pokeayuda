# PokéAyuda

App para el móvil (PWA) que ayuda en los combates Pokémon: buscador con stats base y debilidades, editor de equipo y consejero de combate. Datos e imágenes de [PokeAPI](https://pokeapi.co).

Ábrela en el móvil y pulsa **Instalar** (Android) o **Compartir → Añadir a pantalla de inicio** (iPhone).
